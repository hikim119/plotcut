# PlotCut

**영화 자막 하나**만 넣으면, 리캡 대본을 쓰고 그 대본대로 **컷편집·대사자막·나레이션자막이 전부 배치된 CapCut 프로젝트를 자동 생성**하는 프로그램입니다.

CapCut을 열면 미세조정만 하면 되는 상태로 만들어 줍니다.

내부에서 이걸 다 자동으로 합니다:
- **대본 쓰기** → 자막을 읽고 줄거리 하나를 골라 「타임라인 대본」 txt를 씀 (이미 로그인된 코딩 에이전트를 빌려 씀 — **API 키 불필요, 추가 요금 0원**)
- **대사 되찾기** → 대본에 적힌 대사를 원본 자막에서 찾아 **실제 시각과 줄바꿈**을 복원
- **컷 계산** → 대사가 나오는 순간만 잘라 이어 붙이고, 나레이션은 그 사이 무성 구간에 배치
- **CapCut 드래프트 조립** — 자막은 **맨 아래 한 자리에 고정**, 단은 트랙을 고르는 데만 쓴다(단마다 트랙 하나 + 제목)

---

## 설치 방법

> ⚠️ 최초 1회만. 인터넷 연결 필요
>
> **CapCut을 먼저 깔아야 합니다.** PlotCut은 CapCut의 드래프트 폴더에 프로젝트를 써 넣기 때문에, CapCut이 없으면 만들 곳이 없습니다.

1. **CapCut 설치** — [capcut.com](https://www.capcut.com/) (인터내셔널 버전)
2. **CapCut을 한 번 실행해 빈 프로젝트를 만들고 닫기** — 이때 드래프트 폴더가 처음 생깁니다
3. **CapCut 종료** — 꼭 꺼야 하는 건 아니지만, 새 프로젝트는 CapCut을 **다시 켜야**
   목록에 나타납니다. PlotCut은 기존 프로젝트를 건드리지 않고 늘 새 폴더만 만듭니다
4. 폴더 안의 **`setup.bat`** 더블클릭
5. 끝나면 바탕화면의 **PlotCut** 바로가기로 실행

> 💡 "Windows의 PC 보호" 경고가 뜨면 **추가 정보 → 실행**.
>
> ⏳ `setup.bat`은 **1~2분**이면 끝납니다. GPU도 PyTorch도 쓰지 않습니다.

### 대본까지 자동으로 쓰게 하려면 (선택)

대본을 직접 쓸 거면 건너뛰어도 됩니다. 자동으로 쓰게 하려면 **코딩 에이전트 CLI** 하나가 필요합니다.

- 폴더 안의 **`Codex설치.bat`** 더블클릭 → Node.js + Codex CLI 설치 → **"Sign in with ChatGPT"** 선택
- ChatGPT Plus 구독에 포함됩니다. **API 키 옵션은 고르지 마세요** — 그건 따로 과금됩니다
- Claude Code CLI가 이미 깔려 있으면 그것도 자동으로 인식합니다 (GUI의 `대본 생성기`에서 고름)

PlotCut 자체는 LLM을 부르지 않습니다. 이 에이전트는 **대본 txt를 만드는 단계에서만** 쓰이고, 대본을 직접 넣으면 아예 실행되지 않습니다.

### 설치 문제 해결

**`curl: (23) client returned error on write ...` / `Python download failed`**
setup.bat이 Python을 자동으로 받다가 실패한 경우입니다 (백신이 .exe 다운로드를 차단하거나 디스크 용량 부족). **Python을 직접 설치**하면 됩니다:
1. https://www.python.org/downloads/ 에서 **Python 3.11** 다운로드 (브라우저로 받기)
2. 설치 시 **"Add python.exe to PATH" 체크** ⚠️ (필수)
3. 설치 후 **`setup.bat` 다시 실행** — Python이 있으면 다운로드를 건너뜁니다

**`ffmpeg not on PATH yet` / `Node.js is not on PATH in this window yet`**
방금 설치한 프로그램은 **이미 열린 검은 창에서는 PATH가 안 잡힙니다.** 창을 닫고 그 `.bat`을 한 번 더 누르면 됩니다.

**`[WARN] CapCut not found on this PC`**
CapCut 없이도 setup은 끝까지 진행됩니다. 나중에 CapCut을 깔고 `setup.bat`을 다시 실행하세요.

**설치 후에도 실행 안 됨** — `setup.bat`을 한 번 더 실행하거나, 검은 창의 마지막 오류 메시지를 확인하세요.

## 사용 방법

### 1. 파일 넣기 (드래그 앤 드롭 — 종류 자동 인식)

| 파일 | 설명 |
|------|------|
| **1. 타임라인 대본 (txt)** | **선택** — 비우면 영화 자막을 읽고 대본을 대신 써 줍니다 |
| **2. 영화 자막** | srt · smi · sami · vtt · ass · ssa. **컷 위치의 출처**입니다 — 대본의 대사를 여기서 찾아 실제 시각을 복원합니다 |
| **3. 영화 파일** | **선택** — mp4 · mkv · avi · mov · ts · webm 등. 없으면 자막·타임라인만 든 프로젝트가 만들어지고, 영상은 나중에 채울 수 있습니다 |

> **영화는 1개 파일만** 넣습니다 (CD1/CD2로 쪼개진 영화는 지원하지 않습니다).
> 한국어가 아닌 자막이어도 됩니다 — 대본은 **무조건 한국어로** 나옵니다.

### 2. 설정

- **프로젝트명** — CapCut 홈에 표시될 이름. 첫 파일을 넣으면 파일명에서 자동으로 채워지고, 고쳐도 됩니다 (중복 시 자동으로 `_2` 붙음)
- **영화 제목** — **모르면 비워 두세요.** 적으면 에이전트가 아는 줄거리·결말로 어느 장면이 결정적인지 고릅니다.
  자막만 읽어서는 화면에서 벌어지는 일이 안 보이는데, 특히 액션·코미디가 그렇습니다.
  파일 이름이 `English.srt` 처럼 제목이 아닐 때 특히 도움이 됩니다 (모르는 영화면 자막만 보고 씁니다)
- **나레이션 구간 음소거** — **기본 꺼짐.** 켜면 나레이션 밑에서 원본 대사가 새는 구간만 지웁니다 (컷이 더 잘게 쪼개집니다)
- **서로 다른 대본 3개 뽑기** — **기본 꺼짐.** 켜면 대본을 3개 뽑아 `results/…/후보1~3/` 에 전부 남기고, 각각 어느 구간을 썼는지·줄거리 첫 줄을 한 줄씩 보여 줍니다 (약 3배 느림). 기본은 후보1로 이어서 만들고, 다른 게 마음에 들면 그 폴더의 대본을 쓰면 됩니다.
  - **고르는 건 사람이 합니다.** 에이전트에게 순위를 매기게 해 봤는데, 같은 대본 3개를 두 번 재우니 순위가 재현되지 않았습니다(켄달 τ 0.33 · 합의 1위 3편 중 1편). 재현이 안 되는 판정을 「가장 좋은 것」이라고 팔지 않습니다

- **대본 길이** — 목표 초 (기본 180초)
- **연출 지시** — 대본을 쓸 때 반영할 요구사항. 비워도 됩니다
  > 남자 주인공 이름은 잭, 여자 주인공은 에이미로 써 줘
  > 잭이 에이미를 처음 만나는 장면부터 시작해 줘
  > 나레이션은 짧게, 결말은 끝까지 감춰 줘
- **대본 생성기** — Codex / Claude Code 중 로그인된 것. 로그인 상태가 옆에 표시됩니다

### 3. 실행 (2가지 버튼)

| 버튼 | 필요한 입력 | 결과 |
|------|-------------|------|
| **▶ CapCut 프로젝트 만들기** | 자막 (+대본·영화는 선택) | 대본이 없으면 먼저 써서, 컷 + 자막이 든 CapCut 프로젝트까지 한 번에 |
| **대본만 만들기** | 자막 | 「타임라인 대본」 txt만. CapCut은 건드리지 않습니다 |

> 두 버튼 다 결과 대본에 **대사마다 시각을 박아** 둡니다 —
> 그 대본 하나만 있으면 자막 파일 없이도 다시 만들 수 있습니다.

- **중단** — 진행 중인 작업을 즉시 끊습니다 (에이전트 프로세스까지 종료)
- **초기화** — 넣은 파일과 설정을 비웁니다

> 대본 쓰기는 **7~8분** 걸립니다. 진행바가 실제 경과로 차오르고, 창 제목에 %가 표시됩니다.
> 대본이 이미 있으면 CapCut 프로젝트 생성은 **몇 초**면 끝납니다.

### 4. 결과 확인

- **CapCut 드래프트** → CapCut을 **껐다 켜면** 홈에 새 프로젝트로 나타남
  (CapCut은 켤 때 드래프트 폴더를 훑어 새 프로젝트를 목록에 넣습니다. 켜 둔 채로
   만들어도 기존 프로젝트가 망가지지는 않지만, 다시 켜기 전엔 안 보입니다)
- **결과 파일** → `results/프로젝트명/` 폴더 (실행 건별로 정리)
- **`[줄거리]` 탭** — 대본을 고치기 전에 **먼저 읽어 보세요.** 에이전트가 대본을 쓰기 전에
  정리한 줄거리·결말이 들어 있습니다 (`results/…/줄거리.txt`)
- **`[타임라인 대본]` 탭**에서 대본을 직접 고치고 **`저장하고 다시 만들기`** 를 누르면 그 자리에서 다시 만듭니다
- **`나레이션 복사`** — 나레이션만 **화면과 같은 조각**으로 끊어 클립보드에 복사합니다. 타입캐스트 같은 TTS에 붙여넣어 mp3를 받은 뒤 **CapCut에 직접 끌어다 놓으세요**

로그에 `⚠ 자막에서 못 찾은 대사 문단 N개`가 뜨면 그 문단은 시각을 못 찾아 글자수로 추정 배치된 것입니다. 대본에서 그 대사를 자막 원문대로 고치세요.

## 대본 포맷

```
좋아한다는 말 대신 몰래 그의 삶에 들어간 여자        ← 제목 (첫 줄)

[01:25:03 ~ 01:25:07]                              ← 블록 = 영화 구간

우리 집에서 뭐 해요?                                ← 대사 = 자막 원문 그대로

시간 있으면 오랬잖아요

(좋아하는 남자의 집에 몰래 들어왔다가 딱 걸려버린 여자)   ← 나레이션 = 더빙할 줄
```

빈 줄이 문단 구분, `[…]`가 블록 구분, `(…)`가 나레이션입니다. 규칙 전문은 `AGENTS.md`에 있습니다.

대사 줄 앞에 시각이 박혀 있으면(`@01:25:02.80~01:25:04.29 우리 집에서 뭐 해요?`) **자막 파일 없이 대본과 영화만으로도** 프로젝트를 만들 수 있습니다. 시각은 만들 때 자동으로 박히므로, 한 번 만든 프로젝트의 `results/…/…_타임라인 대본.txt`는 그 자체로 완결됩니다.

자막도 없고 대본에 시각도 없으면 컷을 블록 범위에 **균등 배치**합니다 — 대사가 나오는 순간과 어긋납니다. 로그에 경고가 뜨지만 **멈추지는 않습니다.** `✔ 대본 블록 18 · 대사 48(서명 0 · 병합 0 · 유사 0)` 처럼 매칭이 0으로 나오면 그 상태입니다 — 자막을 같이 넣으면 정확해집니다.

## 동작 원리

1. 자막을 읽고 줄거리 하나를 골라, 훅 → 시간순 → 결말 순서로 블록을 짠 대본 txt를 씀
2. 대본의 대사 문단을 자막 큐와 맞춰 **실제 시각과 줄바꿈**을 복원 (공백·문장부호를 지운 서명 일치 → 연속 2큐 병합 → 유사도)
3. 대사마다 앞 0.2초·뒤 0.3초 여유를 주되 **이웃 자막 간격의 절반**을 넘기지 않게 잘라, 같은 대사가 두 번 들리지 않게 함
4. 나레이션은 글자수로 길이를 추정해 앞뒤 무성 구간에 끼워 넣음 (음소거 옵션을 켜면 그 밑에서 대사가 새는 구간만 볼륨 0)
5. 1초 이내로 붙은 컷은 하나로 이어 붙여 미세 점프컷 제거
6. 자막을 **맨 아래 한 자리**에 배치한다 (단은 트랙 고르기용) — 아래 항목 참고
7. CapCut 드래프트 조립 (영상 1트랙 + 단마다 자막 트랙 + 제목, 세로 1080×1920)

## 줄거리 탭

대본을 쓰기 **전에** 에이전트가 줄거리를 정리해 `results/…/줄거리.txt` 에 남깁니다.
GUI의 `[줄거리]` 탭에서 바로 볼 수 있습니다.

```
[줄거리]              누가 무엇을 하다가 어떻게 되는지 (시간순)
[결말]                마지막에 어떻게 끝나는지 — 숨기지 않고 그대로
[이 대본에서 고른 것]  여러 줄기 중 무엇을 골랐고 무엇을 버렸는지, 왜
[자막에 안 나오는 것]  화면에는 보이는데 대사로는 안 나오는 것
```

**편집하기 전에 먼저 읽으라고 두는 것입니다.** 영화를 안 보고 대본만 고치면
어느 장면이 왜 거기 있는지 몰라서 엉뚱한 데를 지우게 됩니다.

읽기 전용입니다 — 여기서 고쳐도 결과가 달라지지 않습니다. 자막에서 읽어낸 것만
쓰라고 지시하고, 모르는 건 "자막만으로는 알 수 없음"으로 적게 했습니다.

## 자막이 놓이는 방식

자막은 **한 번에 하나만** 뜹니다. 대사가 끝나면 지워지고 다음 자막이 뜹니다 —
같은 글자가 뒤에 또 나오지 않습니다.

자막 **자리는 안 움직입니다** — 전부 화면 맨 아래 같은 높이입니다
(`capcut_draft.SUB_Y0`). 한때 블록 안에서 한 단씩 올렸는데 화면에서 자막이
기어 올라가 보여서 되돌렸습니다.

「단」은 남아 있지만 **트랙을 고르는 데만** 씁니다 — 한 문장의 조각들이 같은
트랙에 모여야 CapCut 에서 문장 단위로 스타일을 고칠 수 있기 때문입니다.

```
[블록 1]                              [블록 2]

  0.20~1.53초   우리 집에서 뭐 해요?      6.89~10.40초  (사실 얼마 전…)
  1.53~4.12초   시간 있으면 오랬잖아요    10.40~14.52초  오면 이 편지 좀…
  4.12~6.89초   (좋아하는 남자의 집에…)
                ↑ 전부 같은 높이
```

대사는 흰색, 나레이션은 연노랑입니다. 자막 길이는 **다음 자막이 나올 때까지**라
컷 사이가 비지 않습니다(레퍼런스 대본 기준 화면이 비는 시간 0.2초 / 168.5초).

**나레이션은 조각으로 잘려 차례로 뜹니다.** 한 문장이 1~4조각(한 줄 최대 14자)으로
나뉘어 순서대로 올라옵니다 — 실제로 잘 나간 숏츠 3편이 그렇게 합니다. 대사는
다릅니다: **한 줄 최대 19자**로, 자막 한 줄이 그대로 한 카드입니다.

**단마다 CapCut 트랙이 하나씩** 있습니다(+제목 트랙). 시간이 안 겹치니 한 트랙에
몰아넣어도 되지만, 그러면 "몇 번째 단"을 통째로 골라 스타일을 바꿀 수가 없습니다.
한 문장의 조각들은 **같은 단**에 들어갑니다 — 안 그러면 한 문장이 세 트랙에
흩어져 문장 단위로 못 고칩니다. 8단까지 올라갑니다(`layout.SUB_ROWS_MAX`).
화면 위치는 전부 같습니다(`capcut_draft.SUB_Y0`).

## 알아둘 것

- **덮어쓰기를 하지 않습니다.** 같은 이름이면 `이름_2`로 **새로** 만듭니다 — CapCut에서 손으로 한 편집이 사라질 일이 없습니다
- **원본 소리는 100% 그대로 둡니다.** 나레이션 구간에서 영화 소리를 지우고 싶으면 `나레이션 구간 음소거`를 켜세요
- **나레이션 길이는 추정값**(120 ms/단위)입니다. 실측 중앙값이 114라 전체 합으로는 3.5% 수준 오차 — 나중에 더빙을 얹어도 자리가 크게 어긋나지 않습니다
- **자막과 영상의 릴리즈가 다르면** 싱크가 어긋납니다. 자막 끝/영화 길이 비율이 이상하면 경고합니다
- **영화 파일은 선택**입니다. 없으면 자막·타임라인만 든 프로젝트가 만들어지고, 나중에 영화를 넣고 다시 만들면 영상이 채워집니다

## 결과 폴더

`results/` 바로 아래에는 **프로젝트 폴더만** 생깁니다. 입력 파일이 있던 자리에는 아무것도 쓰지 않습니다.

```
results/<프로젝트명>/
  <영화명>_타임라인 대본.txt     범위를 다시 계산해 넣은 사본
  줄거리.txt                     줄거리 · 결말 · 무엇을 골랐는지
  narration.txt                  TTS 붙여넣기용 (화면과 같은 조각)
  state.json                     CapCut 식별자 · 입력 지문 · 컷 목록
                                 (**기록이다** — 도구가 다시 읽지 않는다.
                                  build 는 매번 새 프로젝트를 만든다)

results/<프로젝트명>_대본만만들기/
  <영화명>_타임라인 대본.txt     [대본만 만들기] 결과
```

겹치면 번호가 접미사 **앞**에 붙습니다 — `<프로젝트명>_2_대본만만들기`.

## CapCut 업데이트로 드래프트가 안 열릴 때

CapCut 버전이 크게 바뀌면 프로젝트 구조가 달라질 수 있습니다.
CapCut에서 샘플 프로젝트(영상 1개)를 하나 만들어 저장한 뒤,
그 폴더로 `template/skeleton/` 을 교체하면 됩니다.

번들된 템플릿은 **CapCut 8.9.1**에서 뜬 것입니다. `setup.bat`과 프로그램이 설치 버전을 확인해서 다르면 알려 줍니다.

## 다른 컴퓨터에서 쓰려면

**CapCut 위치는 자동으로 맞춰집니다** (`%LOCALAPPDATA%`로 그 컴퓨터의 CapCut 폴더를 자동 탐색). 생성물에도 기기 고유정보나 특정 사용자 경로가 들어가지 않습니다.

다만 다음 조건이 필요합니다:

1. **Windows + CapCut 인터내셔널 버전** 설치 (중국판 젠잉/JianYing은 드래프트를 암호화해서 지원 안 됨)
2. **Python 3.10+** — PlotCut 폴더에서 `setup.bat` 실행 (1~2분)
3. **ffmpeg** — 영화 길이·해상도를 읽는 데 씁니다 (setup.bat이 자동 설치 시도)
4. **대본 자동 생성을 쓸 거면** Codex 또는 Claude Code CLI + 각자의 구독 로그인

## 시스템 요구 사항

- Windows 10 / 11, Python 3.10+
- CapCut 데스크톱 (인터내셔널)
- GPU 불필요

## 개발자용

```bat
python cli.py script <자막.srt> --seconds 180 --title "중경삼림"   :: 대본만 만들기
python cli.py script <자막.srt> --candidates 3                 :: 서로 다른 대본 3개
python cli.py check  <대본.txt> --srt <자막.srt>      :: 대본을 자막과 대조
python cli.py build  <대본.txt> --srt <자막.srt> --movie <영화.mp4> --name 이름
python cli.py list                                   :: results/ 프로젝트 목록
python selftest.py                                   :: 회귀 테스트 (전부 통과해야 함)
```

| `movie_info.py` | ffprobe |
| `selftest.py` | 회귀 테스트 |
